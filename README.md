# Diaz Amantajati Susilo Portfolio

A minimal editorial portfolio built with Next.js, Tailwind CSS, and GSAP. The site presents selected frontend, Web3, AI, and payment-interface work from Diaz Amantajati Susilo's CV.

## Stack

- Next.js App Router
- React
- Tailwind CSS
- GSAP
- Lucide React

## Development

```bash
npm run dev
```

Open `http://localhost:3000`.

## Verification

```bash
npm run lint
npm run build
```
